2. WHAT WAS BUILT

Key Screens and Flows

The prototype contains 10 fully interactive screens across 3 complete customer journeys + bonus demo features:

  1. Home Screen — Personalised discovery feed with AI recommendations, friend activity section ("Friends going to events"), social discovery ("Popular with friends"), Unsplash event images, and AI disclosures.
  2. Event Detail — Hero image (Unsplash), all-in pricing, tappable Fair Price Indicator with tooltip overlay, Price Breakdown modal, "Find Tickets" and "Go Together" buttons, social proof ("Sarah and 3 friends are going").
  3. Seat Selection — Section-based selection with all-in prices, list view, checkout button.
  4. Queue Experience — Queue position, wait time, progress bar, price guarantee badge, push notification opt-in, ARIA chat access, "Skip Queue for Demo" button.
  5. Payment — Payment form with order summary showing all-in total.
  6. Confirmation — Celebration screen with ticket details, QR code, "My Tickets," "Add to Calendar," and "Invite Friends" buttons.
  7. ARIA Assistant — Chat interface with expanded quick-action chips (Order Status, Transfer Ticket, Account Help, Refund Help, Accessibility Info, Talk to Human), conversational AI responses, human escalation flow.
  8. My Tickets — Upcoming and Past tabs. Upcoming: ticket QR codes, countdown, event details. Past: post-event recap cards with "Rate" and "See Similar" actions. "Your Year in Live" entry card.
  9. "Your Year in Live" — Full-screen swipeable retrospective: title card → events attended → top artist → favourite venue → shareable summary card.
  10. Onboarding — Four-screen flow: Welcome → Genre Selection → Social Features (privacy toggles, default OFF) → Trust Promise.

AI Features

  1. Personalised Recommendation Engine (Recommender System) — personalised event cards with explanations and AI disclosure.
  2. Fair Price Indicator (Intelligent Agent) — badges with tappable tooltip explanations.
  3. ARIA (Chatbot/Intelligent Agent hybrid) — expanded to 6 query types + human escalation + group coordination.
  4. Social Discovery & "Your Year in Live" Engine (Recommender System) — friend activity, social recommendations, post-event recaps, annual retrospective.

Presentation Improvements (Client Feedback)

  • Info panel beside the phone frame with: prototype title, feature tags, journey guides, and demo instructions
  • Unsplash images for all event cards and hero images — professional concert/venue photography
  • Clear journey navigation — 3 labelled journey buttons in the info panel: "Discovery to Purchase," "Queue Experience," "ARIA Support"
  • Phone frame properly sized and positioned with the info panel sticky on the left

3. HOW TO DEMO IT

Open the HTML file in any modern browser. The prototype displays with an info panel on the left and a phone frame on the right.

Demo Journey 1: Discovery to Purchase

  1. Start at Home Screen. Show the personalised greeting, AI-powered recommendations with real concert images, and the AI disclosure banner. Point out the "Friends going to events" section and "Popular with friends."
  2. Tap "Taylor Swift — The Eras Tour" event card. Event Detail screen loads with a concert image, all-in pricing (€89.50), and the Fair Price Indicator badge.
  3. Tap the Fair Price Indicator badge. A tooltip overlay appears: "Great value — similar events at this venue average €100–€130." This is the trust-building moment.
  4. Tap "Price Breakdown." Modal shows transparent fee breakdown.
  5. Tap "Find Tickets." Seat Selection screen with sections and all-in prices.
  6. Select a section, tap "Checkout." Payment screen with all-in total.
  7. Tap "Pay." The Confirmation screen celebrates: "You're going!" with ticket details, QR code, and "Invite Friends" button.

Demo Journey 2: Queue Experience (High-Demand)

  1. From Home, tap "Oasis — Croke Park." This high-demand event triggers the Queue Experience.
  2. Queue screen shows: Position #4,521, estimated wait 12 minutes, price guarantee badge.
  3. Tap "Notify Me" — push notification opt-in.
  4. Tap "Skip Queue for Demo" — transitions to "It's Your Turn!" screen with direct link to seat selection.

Demo Journey 3: ARIA Support

  1. Tap the ARIA tab in bottom navigation.
  2. Note the AI disclosure. Tap quick-action chips: "Order Status," "Refund Help," "Accessibility Info," "Talk to a Human."
  3. Observe human escalation — ARIA transfers to a named human agent with full conversation context.

Bonus: Post-Event Engagement

  1. Tap "My Tickets" → switch to "Past" tab.
  2. See post-event recap cards with "Rate" and "See Similar Events" prompts.
  3. Tap "Your Year in Live" to open the full retrospective experience.
  4. Swipe through cards showing events attended, top artist, favourite venue, and shareable summary.

Bonus: Onboarding

  • Tap "Profile" → "Restart Onboarding" to see the 4-screen flow including the new Social Features opt-in screen.

SIMPLIFIED ⚠️

  • "Your Year in Live" — 4 cards instead of Galadriel's specified 5 (combined venue/genre into one card). Shareable card built as specified.
  • Seat map — section-based selection (per Galadriel's flexible area)
  • ARIA responses — pattern-matched for demo scenarios (per Galadriel's flexible area)
  • Personalisation engine — pre-determined recommendations
  • Fair Price Indicator — pre-set values per event
  • Group booking — simulated with pre-set friend states (per Galadriel's flexible area)
  • Friend activity — pre-set data showing simulated friend attendance
  • Social proof — pre-set numbers ("Sarah and 3 friends are going")

DEFERRED ❌

  • Monthly summary — deferred per Galadriel's guidance. Post-event recap + annual retrospective are built.
  • Actual payment processing — simulated flow
  • Push notifications — opt-in UI built, delivery requires native mobile
  • Real-time queue — simulated with demo skip button
  • Real social graph — friend data is simulated; production requires contacts API integration
  • Shareable image generation — "Share to Stories" button is functional UI but actual image export requires canvas/server-side rendering
  • Full accessibility testing — semantic HTML and ARIA labels implemented but not tested on real devices

5. KNOWN LIMITATIONS

  1. All AI features are simulated. Recommendations, Fair Price Indicator, ARIA, and social discovery use pre-scripted responses and pre-set data.
  2. Social features use simulated friend data. The friend activity, group booking, and "Popular with friends" sections display pre-set data. Production implementation requires contacts API integration and mutual consent verification.
  3. "Your Year in Live" shareable card is visual only. The "Share to Stories" button shows the card but does not generate a downloadable image. Production implementation requires HTML canvas or server-side image rendering.
  4. Queue progression is demo-controlled. "Skip Queue for Demo" button simulates the transition.
  5. Single HTML file with no backend. Data does not persist between sessions.
  6. Lucide Icons CDN dependency. Icons load from unpkg.com/lucide@latest with text fallbacks.
